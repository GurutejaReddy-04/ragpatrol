RAGPatrol

Automated Quality Gating, Faithfulness Auditing, and Latency Profiling for Production RAG Systems

RAGPatrol is a surgical regression gating and observability harness designed to evaluate black-box Retrieval-Augmented Generation (RAG) systems across retrieval precision/recall/F1, answer faithfulness, and latency percentiles. It persists benchmark runs over time in SQLite or PostgreSQL, supports side-by-side configuration comparisons, and gates CI/CD pipelines against quality degradations.

⭐ View on GitHub 🚀 Quick Start Guide 📊 Comparison Mode
🎯

Classical Retrieval Scoring

Computes Precision, Recall, and F1 across version-controlled ground-truth chunk IDs with strict set-based alignment and edge-case resilience.

🧠

Dual-Signal Faithfulness

Combines local embedding similarity (SentenceTransformers) with an LLM-as-a-judge (Google Gemini) to detect hallucinations without open-world conflation.

⏱️

Latency Percentile Profiling

Measures p50, p95, and p99 wall-clock latencies, contrasting cold-cache vs. warm-cache states and computing exact speedup multipliers.

🚦

Automated CI/CD Gating

Detects quality regressions (>5% drop in retrieval, >10% in faithfulness, >20% latency inflation) and halts CI workflows before bad releases reach users.

⚖️

Side-by-Side Comparison

Directly compares two configurations (e.g., cross-encoder reranker enabled vs. disabled) with automated metric winner identification.

🔌

Generality Proof

Includes an independent mock RAG service with an alternative API schema to prove true vendor-agnostic portability.
